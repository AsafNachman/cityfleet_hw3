## איך בונים ומריצים

צריך `g++` עם C++17/C++20 ו-`make`. מתיקיית הפרויקט:

```bash
make clean
make
make run
make cpp20
```

`make` בונה ב-C++17, `make run` מריץ, `make cpp20` בונה ומריץ ב-C++20. `make clean` מוחק את ההרצות.
